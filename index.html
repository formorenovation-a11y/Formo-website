Conecta Firebase para guardar en la nube

Sin Firebase, los cambios solo se guardan en este navegador. Con Firebase, los cambios se guardan en la nube y se ven en todos los dispositivos y visitantes del sitio.

📋 Cómo configurar Firebase (5 minutos, gratis)

Ve a console.firebase.google.com e inicia sesión con tu cuenta de Google

Haz click en "Crear un proyecto" → ponle un nombre (ej: formo-site) → continúa hasta crear el proyecto

En el menú izquierdo busca "Realtime Database" → click en "Crear base de datos"

Selecciona la región más cercana y elige "Comenzar en modo de prueba" → click "Habilitar"

Copia la URL que aparece (se ve así: https://tu-proyecto-rtdb.firebaseio.com)

Pégala aquí abajo y haz click en "Verificar y Conectar"

Ejemplo: https://formo-site-default-rtdb.firebaseio.com

⚠️ El modo de prueba de Firebase dura 30 días. Después deberás actualizar las reglas en la consola. Te enviaremos instrucciones.

📷 Firebase Storage — Photo Uploads

▼
Bucket configurado: formo-renovation-aa189.firebasestorage.app

Si las fotos dicen "Upload failed", las reglas de Storage expiraron. Copia y publica estas reglas:

rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /{allPaths=**} { allow read, write: if true; } } } 
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}

Firebase Console → Storage → Rules tab → reemplaza todo → Publish

Default hardcoded: formo-renovation-aa189.firebasestorage.app

🔒 Security Rules

▼

Cuando expire el modo de prueba, ve a Firebase Console → Realtime Database → Reglas y pega esto:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}

Esto permite que cualquier visitante lea el sitio pero solo tú puedas escribir desde el panel.

Answers About Our Services

Painting

We provide interior and exterior painting including walls, ceilings, trim, baseboards, crown molding, doors, cabinets, accent walls, exterior siding, fascia, soffits, front doors, and garage doors.

We commonly recommend Sherwin-Williams and Benjamin Moore for their excellent durability, coverage, and long-term performance.

Yes. Drywall repairs can be completed before painting whenever included in the approved scope. If additional damage is discovered, we'll review findings and provide pricing before proceeding.

Drywall

Installation, repairs, finishing, Level 5 finish, skim coating, ceiling repairs, crack repairs, texture matching, and surface preparation for painting.

The highest quality drywall finish — a full skim coat over the entire surface for an exceptionally smooth result. Ideal for modern homes, luxury finishes, and areas with natural or direct lighting.

Flooring & Tile

LVP, Laminate, Engineered Hardwood, Hardwood, and Tile Flooring — including removal of existing flooring and whole-home replacements.

We install tile for showers, bathroom walls, floors, kitchen backsplashes, fireplace surrounds, accent walls, and laundry rooms. All showers include proper waterproofing.

Carpentry & Remodeling

Baseboards, crown molding, door casing, window trim, wainscoting, built-in shelving, custom storage, accent walls, decorative ceiling beams, fireplace trim, and custom wood features.
